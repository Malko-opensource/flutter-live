# 2D Dash assets

The current illustration sources, editable Blender rig and render scripts are in [illustrated](illustrated/README.md).

- Three costumes: hanbok, gat/durumagi, and dancheong stage outfit.
- Eight animated states: idle, listen, speak, wave, celebrate, reconnect, sing, megaphone.
- Runtime: 24-frame RGBA atlases at 12 fps, 512 px per frame.
- The Flutter app and native overlay load the committed atlases; Blender is not needed to build or run the app.

Earlier design experiments are excluded from the public repository. See [third-party notices](../../THIRD_PARTY_NOTICES.md) for artwork provenance.
