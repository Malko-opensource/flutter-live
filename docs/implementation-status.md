# 구현 및 검증 현황

2026-11-04. Tauri 2 + Svelte 5 재구현이다. 기존 Flutter 코드·설정·테스트를 제거했다. 내부 디자인 패키지와 로컬 빌드 결과물은 저장소에 포함하지 않는다.

## 구현

- Atlas 디자인팩 Linear 스타일의 실제 Svelte Provider, Button, Input, Select, Tabs.
- 대화·오버레이 두 모드, 현재 자막, API 키 설정, 로컬 마이크 테스트.
- Tauri 메뉴바와 독립 투명 자막 창, 창 숨김·복귀.
- 새 Swift 호스트의 입력 장치 선택, PCM 변환, 제한된 예약 재생, 시스템 오디오.
- TypeScript Gemini WSS, 제한된 재연결 버퍼, 인터럽트 및 세션 재개.
- 기존 제작 2D Dash 에셋을 `public/dash`로 이전, 세 의상·여덟 동작.

- 통신·세션·표시 설정 자동 테스트: 24개 통과. setup gate, 버퍼 상한, 인터럽트, 재연결·중지, 비밀 정보 없는 오류, 언어 설정, PCM 레벨, 송신 지연 시 상한, 출력 샘플레이트 검증.

- 실제 Tauri 앱에서 대화·설정·오버레이 제어 화면과 Dash 미리보기 렌더 확인. 독립 자막 창에 샘플 번역이 표시되고 메인 창 열기 버튼으로 복귀함을 확인.

- 최소 680×600 웹뷰 크기에서 내부 스크롤·고정 하단 버튼을 확인했다.

## 언어 방향 수정 (2026-11-04)

- 지원 언어를 한·영·일·중으로 제한하고 양쪽 목록에 모두 표시한다. 같은 언어 선택 시 교환하며 12개 방향 조합을 테스트한다. 실제 앱에서 원문 목록에 네 언어와 English 선택, English → 한국어 고정 방향 표시를 확인했다. 캡처: `verification/presentation-languages.jpg`.

- 발표용 오버레이는 원문 언어 → 번역 언어를 지정한다. 입력 전사에는 원문 언어 힌트만 보내고 모델에는 고정 목표 언어 지시를 보낸다. 음성 모델이 지원하지 않는 speechConfig.languageCode는 사용하지 않는다.
- 대화 모드는 두 언어 힌트와 발화별 양방향 지시를 사용한다. 서버의 languageCode가 있을 때만 감지 언어를 표시한다.
- interimInputTranscription은 이전 임시 자막을 교체하며 확정 자막과 중복 결합하지 않는다.
- 통역 중 모드 전환은 기존 연결을 중지한다. 화면만 바뀌고 이전 번역 지시가 계속 쓰이는 것을 방지한다.
- 자동 테스트는 요청 설정·메시지 처리·세션 전환의 검증이다. 실제 음성의 언어 전환 정확도 검증은 아니다.
- API 근거: [Live WebSocket 명세](https://ai.google.dev/api/live), [Native audio language behavior](https://ai.google.dev/gemini-api/docs/live-api/capabilities#change-voice-and-language).

## Linear 및 표시 설정 (2026-11-04)

- 디자인팩 `765b3c4`의 Linear 스타일로 교체. 어둡게·밝게·시스템 테마, 세 글꼴, 화면 글자 90–130%, 자막 18–48px, 자막 배경을 선택한다.
- 변경 즉시 미리 보고, 취소하면 원복한다. 적용한 표시 설정만 로컬에 저장한다. API 키와 발화는 저장하지 않는다.
- Stageshow의 정보 위계와 상태 전환 원칙을 적용했다. 선택한 언어로 원문 → 번역 → 완성 자막이 이어지고, 결과를 유지한다. 모션 줄이기 설정도 따른다.
- 브라우저에서 밝은/어두운 화면, 최대 크기, 최소 창 크기, 취소 복구, 적용 후 새로고침 유지 확인. 실제 Debug 앱에서 Linear 화면·설정·독립 자막 렌더 확인. 48px 설정의 재시작 유지와 900×270 자막 창에서 번역 두 줄·원문 표시를 확인하고 기본 표시값으로 복원.
- 세부 근거와 Stageshow 검증 범위: `design-rehearsal.md`. 자동 촬영 게이트 통과를 주장하지 않는다.
- Linear 및 표시 설정 변경은 v0.2.1 배포 대상이다. 기존 v0.2.0에는 포함되지 않는다.

## 모드별 모델 고정 (2026-11-06)

- 모델 입력란과 사용자 설정의 모델 값을 제거했다. WebSocket setup에서 모드별 고정 정책을 사용하며, 재연결에도 같은 정책을 적용한다.
- 현재 두 모드 모두 `gemini-3.8-live`를 사용한다. 대화의 양방향 지시와 발표의 원문 언어 힌트·고정 목표 언어 지시를 유지한다.
- [공식 Live 모델 안내](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-live)를 확인했다. [Live Translate](https://ai.google.dev/gemini-api/docs/live-api/live-translate)는 별도 translationConfig와 지시문 없는 연결 규약이므로, 이번 입력 UI 제거 작업에서 통역 엔진까지 교체하지 않았다.
- Svelte 검사 오류·경고 0, 테스트 24개 통과, macOS Debug 빌드 성공. 웹 화면에서 API 키 입력만 남은 설정을 확인했다 (`verification/fixed-model-settings.jpg`). 실제 Gemini 호출은 수행하지 않았다.

## 프레젠테이션 번역 경로 보완 (2026-11-07)

- 발표 모드의 `activityHandling`을 `NO_INTERRUPTION`으로 분리했다. 다음 발화가 시작돼도 생성 중인 번역을 끊지 않는다. 대화 모드의 인터럽트·모델·언어 지시는 유지한다. 근거: [Live API ActivityHandling](https://ai.google.dev/api/live#ActivityHandling).
- PCM 전송은 네이티브 캡처 이벤트에서도 즉시 처리한다. 숨겨진 웹뷰의 20ms 타이머에만 의존하지 않으며, 연결 준비 확인·2초 입력 버퍼·64KiB 송신 역압력·회당 4청크 제한은 유지한다.
- 메인 웹뷰의 백그라운드 제한을 비활성화했다. Tauri의 이 설정은 macOS 14 이상에서 지원하며, macOS 13에서는 숨김 상태의 지속 실행을 보장하지 않는다. macOS 13에서는 메인 창을 보이게 유지해야 한다.
- 시작 전·일시 정지·오류 상태에서는 자막을 띄우고 메인 창을 숨길 수 없게 했다. 버튼 옆에 사용 순서를 안내하고, 창을 여는 중 세션이 중지되어도 메인 창을 숨기지 않는다. 디자인 미리보기는 계속 허용한다.
- 자막 창으로 세션 상태와 오류를 전달한다. 실패한 연결이 `말씀해 주세요`로만 보이거나 이전 번역 뒤에 가려지지 않는다.
- 기존 24개에 회귀 테스트 13개를 추가했다. 타이머 없이 PCM 전송, 역압력 해제, 전송 실패·닫힌 소켓, 음소거 상태의 부분 번역, 오버레이 중지 경합과 표시 상태를 검사한다. 실제 Gemini 음성 통역의 재현 또는 품질 검증은 아니다.
- macOS 26.3.1에서 새 Debug 앱을 열어 시작 전 자막 버튼 비활성화, 키 없는 시작의 설정 안내, 취소 복귀, 디자인 미리보기의 창 숨김·자막 갱신, 메인 창 복귀, 종료·자막 숨김을 확인했다. 키 입력·마이크/시스템 오디오 캡처·Gemini 호출은 하지 않았다.
- `gemini-3.8-live`는 턴 기반 모델이므로 이 변경만으로 쉬지 않는 발표의 동시 통역이나 지연을 보장하지 않는다. 실제 발화·API 인증, 5분 이상 숨김 유지, macOS 13 동작은 별도 검증이 필요하다. 전용 Live Translate 모델로의 교체는 이번 수정에 포함하지 않는다.

## v0.2.2 전체화면 및 배포 검증 (2026-11-07)

- AppKit의 `canJoinAllApplications`, `canJoinAllSpaces`, `fullScreenAuxiliary`로 자막 창이 다른 앱의 전체화면 Space에 참여하도록 구성한다. 창을 비활성·숨김 상태로 생성한 뒤 메인 스레드에서 표시하며, Tauri의 NSWindow 클래스와 앱 활성화 정책은 유지한다. 보안 설정이나 접근성 권한은 변경하지 않는다.
- 실제 AppKit 회귀 테스트에서 상충 플래그 제거, floating 레벨, 비활성 상태 유지, 반복 적용과 null 인자를 검증했다. 실행 명령과 수동 검증 절차는 [fullscreen-overlay.md](fullscreen-overlay.md)에 기록했다.
- 최종 v0.2.2 소스로 프런트엔드 37개 테스트, Svelte/TypeScript 오류·경고 0, macOS arm64 Release 빌드가 통과했다. 배포 앱에 ad-hoc 서명을 적용하고 `codesign --verify --deep --strict`를 통과했다. Developer ID 서명·공증은 아니다.
- 정확한 최종 Release 번들을 실행해 오프라인 미리보기 자막, 메인 창 숨김·복귀, 자막 숨김·재열기, 미리보기 중지와 앱 종료를 확인했다. 앞선 Debug 번들에서 별도의 Chrome 창을 전체화면으로 전환·해제했으며 기존 사용자 탭은 보존했다.
- 화면 도구가 앱 창을 개별 캡처하므로 Chrome과 자막의 최종 합성 겹침 순서, Chrome의 키보드 포커스 유지까지 시각적으로 확정하지 않았다. 실제 Gemini 음성 통역, 구버전 macOS, 다중 모니터, 장시간 전체화면 운영도 미검증이다.

## v0.2.3 전체화면 후속 수정 (2026-11-07)

- v0.2.2에서 Chrome 전체화면 위에 자막이 보이지 않는 사용자 보고를 확인했다. 일반 NSWindow에 플래그만 설정하는 방식 대신 실제 `nonactivatingPanel` NSPanel을 생성하고 기존 Tauri 웹뷰를 옮긴다.
- 숨긴 원본 창은 placeholder를 유지하고, 자막의 hide/resize/drag는 새 panel로 연결한다. 키 창·메인 창이 되지 않게 하고 첫 마우스 입력을 허용한다. 앱 전체 활성화 정책·OS 보안 설정·오디오 권한은 바꾸지 않는다.
- 최초 위치를 화면 하단으로 지정하며, 기존 resizable 속성과 크기에 따른 웹뷰 레이아웃을 보존한다. 네이티브 회귀 테스트에서 panel 형식, 소유권, resize, 원본 contentView 복원 등을 검사한다.
- Google 공식 공개 샘플의 실제 Slides 슬라이드쇼 전체화면에서 Debug 자막이 위에 표시되는 합성 화면을 확인했다. 사용자 자료는 수정하지 않았다. 최종 Release 검증과 남은 한계는 릴리스 노트 및 [fullscreen-overlay.md](fullscreen-overlay.md)에 기록한다.

## v0.2.3 무음 대기 및 스트림 복구 (2026-11-07)

- 무음 자체로 캡처를 중지하는 코드는 없었다. 대신 일시 연결 장애를 6회 후 포기하던 제한과 송신 예외 전 청크 제거, 예정된 연결 교체 때 예약 재생을 지우는 문제를 수정했다.
- 250–500ms부터 시작하는 지속 재시도, 정체된 송신 버퍼 감지, 최신 2초·100청크의 성공 후 제거, PCM 공급 중단 시 일회성 audioStreamEnd 및 재개를 구현했다. goAway는 현재 턴 완료/마감까지 기다리고 예정된 회전은 출력 자막·재생을 보존한다.
- 실패한 세션 재개는 새 세션으로 복구한다. 중지/모드 변경 후 늦은 마이크 시작을 차단하고, 네이티브 캡처 오류가 자막 창에 정확히 전달되게 했다.
- 합본 자동 테스트 68개 및 Svelte/TypeScript 검사 통과. 실제 Gemini·마이크·번역 속도 측정은 하지 않았다. 장시간 무음 테스트는 가짜 시계/소켓 기반이며 실제 네트워크 검증이 아니다. [복구 정책 및 제한](live-recovery.md)을 참고한다.

## v0.2.4 응답 처리 및 표시 보완 (2026-11-07)

- 공식 JSON 전사·음성 필드를 타입별로 처리하고, 비동기 Blob 처리 순서 및 같은 패킷의 전사/인터럽트/완료 순서를 보존한다. 임의 태그 삭제나 중복 추정 제거는 하지 않는다.
- 모델 완료와 입력 전사 완료를 분리해 늦은 입력 조각을 버리지 않고 최근 6000자 안에서 유지한다. 인터럽트의 비동기 clear가 다음 자막 상태를 덮는 경쟁 상태를 막았다.
- 긴 번역을 처음 두 줄에서 잘라 두던 표시를 최신 줄 자동 추적으로 바꿨다. 메인 화면·발표 미리보기·독립 자막에서 원문과 번역을 계속 갱신하며, 마크업은 실행하지 않는 평문으로 보존한다.
- 빠르게 몰린 음성을 조용히 버리던 2초 한도를 즉시 예약되는 30초·4096버퍼 예산으로 바꾸고 초과/형식/장치 실패를 알린다. 실제 음성 재생과 통역 지연은 미측정이다.
- [공식 계약 감사 및 한계](live-response-contract.md)에 모델 설정, VAD, 전사 순서, 재연결과 실시간성 제한을 기록한다. 화자 분리나 추가 모델/업체는 도입하지 않는다.
- 프런트엔드 회귀 테스트 83개, Svelte/TypeScript 오류·경고 0, 무음 Swift 재생 예산·패널 테스트, arm64 Release 빌드 및 ad-hoc 코드서명 무결성 검증을 통과했다. 실제 API·발성·오디오 출력·장시간 안정성 검증으로 간주하지 않는다.
- 정확한 v0.2.4 Release 앱에서 오프라인 디자인 미리보기, 대화/발표 화면, 실제 네이티브 자막 표시 및 메인 복귀를 확인했다. 긴 합성 자막·크기별 UI와 전체화면 합성은 이번 버전에서 재검증하지 않았다. 미리보기는 중단했으며 API 호출·녹음·스피커 재생·새 권한 승인은 없었다.
