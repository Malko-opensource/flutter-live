# 구현 및 검증 현황

2026-11-03 기준. 현재 공개 버전은 Flutter macOS PoC입니다.

## 구현

- 자막 오버레이 제어 화면과 양방향 대화 화면, 두 언어 선택, 현재 발화만 표시.
- Gemini Live WSS 연결, 원문·번역 자막과 음성 수신, 인터럽트 시 재생 큐 폐기, 제한된 버퍼와 재연결.
- macOS 메뉴바, 독립 NSPanel 자막, AVAudioEngine 마이크와 ScreenCaptureKit 시스템 오디오.
- Core Audio 입력 장치 목록과 UID 선택, 기본 장치 추적, 연결 변경 및 오디오 형식 변경 대응.
- API 키 없이 작동하는 마이크 입력 레벨 테스트. 테스트 오디오는 저장하거나 서버로 전송하지 않음.
- API 키·모델 설정 페이지. 키는 실행 중 메모리에만 보관.
- 2D Dash: 20개 본, 16개 가중치 메시, 세 의상, 여덟 동작. 앱은 512px 프레임 아틀라스를 12fps로 재생.

## 확인한 결과

- `flutter analyze`: 이상 없음.
- `flutter test`: 20개 통과, 선택적 화면 캡처 1개 제외.
- `flutter build macos --debug`: 성공.
- 실제 앱 창에서 최신 일러스트와 디자인 미리보기를 확인.
- Bluetooth 이어폰을 재연결했을 때 장치 목록과 기본 입력 표시가 갱신됨을 확인.
- 해당 이어폰에서 실제 PCM 입력과 입력 레벨 변화를 확인하고 로컬 테스트를 종료.
- API 키 없는 로컬 테스트에서 Live 연결 및 오디오 전송이 없고, 중지·화면 종료 때 캡처가 정리되는 회귀 테스트.
- 576개 캐릭터 프레임의 투명도·동작·잘림과 Blender 루프 경계 검증.

`docs/verification`의 이미지는 Flutter 위젯 테스트 렌더입니다. 실제 macOS 창 캡처로 간주하지 않습니다.

## 미검증 범위

- 사용자 API 키로 실행하는 Gemini 인증·실제 번역 품질·양방향 언어 감지·지연.
- USB·유선 마이크 실물, 장시간 사용, 모든 장치의 연결 해제·재연결 조합.
- 시스템 오디오 캡처 품질, 스피커 재입력 에코, 실제 전이중 통역.
- 독립 오버레이의 전체 화면·다중 모니터 동작.
- 서명·공증·App Store 배포.

음성 복제, 무지연 동시통역, 음소별 립싱크는 보장하지 않습니다.
